# FE Trainer — підготовка до Strong Middle Frontend

Тренажер в одну сторінку: задачі з автоматичною перевіркою (умова ліворуч, редактор праворуч), квізи «що виведе код», питання співбесід з варіантами відповідей і підручник. Розділ **Фронтенд** покриває HTML, CSS, JavaScript (до ES2025, Temporal), браузер і DOM, Web Components, рушій V8, мережу, безпеку, продуктивність, інструменти, як працює Node.js, тестування, патерни, архітектуру і frontend system design, TypeScript, React 19, Vue 3, наскрізні проєкти (свій фреймворк, бандлер, тест-раннер), алгоритми, live coding і **фінальний проєкт** — тестове завдання «Дошка задач» від шару даних до захисту рішення. Розділ **Бекенд** — далі.

**Повнота перевіряється, а не вгадується:** `tools/syllabus.js` — канонічна програма з 431 теми (javascript.info, MDN Curriculum, roadmap.sh, h5bp Interview Questions, TypeScript Handbook, type-challenges, react.dev, vuejs.org, nodejs.org); `npm run coverage` показує теми без практики.

## Запуск

Відкрийте `index.html` у браузері (Chrome / Edge / Firefox). Інтернет і збірка не потрібні.

Через локальний сервер:

```bash
npm run serve        # http://localhost:5173
```

## Як влаштовано навчання

**Розділи → курси → модулі → кроки → завдання.** Фронтенд: HTML, CSS, JavaScript, Браузер і DOM, Рушій V8, Мережа/безпека/продуктивність, Інженерні практики (з оглядом Node.js), Проєкти, Алгоритми, TypeScript, React, Vue, Фінальний проєкт. Курс — дорожня карта модулів по порядку, модуль — кроки від простого до складного.

**План навчання на головній.** Учень обирає **основний фреймворк** (React, Vue або обидва) і кількість годин на тиждень. Готовність, план і пробна співбесіда рахують лише основний фреймворк; курс другого лишається для порівняння. Для кожного курсу й модуля показано орієнтовний час (квіз ~2 хв, теорія ~4 хв, задача 8–40 хв за рівнем, плюс читання підручника), а план рахує, скільки тижнів лишилось. Досвідчені розробники проходять «Підсумкову перевірку» модуля (10 завдань): від 85% модуль можна позначити знайомим — він випаде з плану.

- **Підручник синхронізований з кроками.** Один розділ на модуль, підрозділ на кожен крок. «Довідник» у завданні відкривається одразу на підрозділі поточного кроку (324 з 324).
- **Без забігання наперед.** Задача використовує лише пройдене (`tools/check-prereqs.js`).
- **Теорія вшита в задачі.** Кожна умова має «Де трапляється» і «Як це працює»; у React і Vue — аналогії з вивченим JS, міні-фреймворком і між собою.
- **Від прикладу до самостійності.** Розбір готового коду → каркас із TODO → задача з нуля.
- **Інтеграція знань.** Курс «Проєкти»: React-подібний фреймворк, бандлер, тест-раннер. У React і Vue ви пишете мінімальні версії інструментів: стор на `useSyncExternalStore`, кеш запитів як у TanStack Query, роутер, `getByRole`, Pinia, роутер з guards, реактивність на Proxy.
- **Квізи не вгадуються за позицією.** Варіанти відповідей перемішуються при кожному показі й повторній спробі; клавіші A–F і підсумок «пропущено: B» відповідають літерам на екрані.
- **Факти перевірені запуском.** Квізи про поведінку React 19, Vue 3.5, Node 24 і браузера перевірені на справжніх рушіях.
- **Активне пригадування.** «Перевірити себе» на модулі; пробна співбесіда з вердиктом рівня.
- **Інтервальне повторення.** Помилки й закладки — у «Повторенні» з інтервалами 1/3/7/16/35 днів.

Рівні: **Junior** → **Middle** → **Strong Middle** → **Senior**.

## Робочі місця

| Розділ | Для чого |
|---|---|
| **Завдання з кодом** | `Ctrl+'` — запустити, `Ctrl+Enter` — перевірити тестами. Консоль (REPL) праворуч: викликайте свої функції |
| **TypeScript** | справжній компілятор (`tsc --strict`, TypeScript 6) офлайн у Web Worker: помилки типів з номерами рядків, тести типів (`Expect<Equal<A, B>>`, `// @ts-expect-error`), консоль виконує TS |
| **React** | React 19 + ReactDOM у sandbox-сторінці, JSX компілює TypeScript; завдання з `lang: 'tsx'` перевіряє `tsc --strict` з `@types/react` 19; тести через `mount`, `act`, `typeInto`, `settle`; перегляд рендерить `App` |
| **Vue** | справжні `.vue`-файли (`<script setup>`, `<template>`, `<style scoped>`), компіляція офіційним `@vue/compiler-sfc` у браузері; `lang="ts"` і `.ts`-модулі перевіряє `tsc --strict` з типами Vue 3; кілька файлів і модулів (`useFetch.js`) в одному редакторі; тести через `mount`, `nextTick`, `typeInto`, `settle` |
| **DOM / CSS** | справжня сторінка 800×600 у sandbox, вкладка «Перегляд» |
| **Квізи й теорія** | один або кілька правильних варіантів, пояснення до кожного варіанта; праворуч — консоль |
| **Пісочниця** | вільний JavaScript, TypeScript, HTML/CSS/JS, React або Vue |
| **Мої задачі** | власні задачі з тестами (`// test: назва`, для TS ще `// type: назва`), зокрема React- і Vue-компоненти: перевірка, що рішення проходить, а стартовий код — ні |
| **Підручник** | 49 розділів: від основ до рівня Senior |
| **Консоль** | плаваюча кнопка «Консоль» або `Ctrl+'` на будь-якій сторінці |

Прогрес зберігається в `localStorage`; у налаштуваннях — експорт / імпорт у JSON. «Скинути все» обнуляє прогрес, власні задачі залишаються.

## Як додати курс (наприклад, Бекенд)

1. У `data/_topics.js` зробіть курс активним (прибрати `status: 'soon'`) і додайте модулі `{ id, title, short, about }`; поле `area` (`frontend` / `backend`) визначає розділ.
2. Створіть `data/<module>.js`: `FE.topic(id, { intro, groups, items })` за [CONTENT_GUIDE.md](CONTENT_GUIDE.md).
3. Якщо потрібне інше середовище, зареєструйте його за зразком `js/react-runtime.js` / `js/vue-runtime.js`:

```js
FERunner.runtimes.mylang = {
  label: 'Назва', files: ['html', 'css', 'js'], fileLabel: 'main.x', mode: 'javascript',
  run(item, files, hooks) { /* перетворити → FERunner.runDom({ ..., prelude }) */ },
  previewDocAsync(opts, previewId) { /* живий перегляд */ }
};
```

   Завдання обирає середовище полем `runtime` (за замовчуванням — за `type`: `code` або `dom`); дозволені значення — у `tools/validate-core.js`.
4. Додайте теми курсу в `tools/syllabus.js`, розділ підручника в `data/book/` (заголовки `## ` = назви кроків) і запис у `data/book/_index.js`, посилання — у `js/docs.js`.
5. Перевірте: `npm run check`.

## Інструменти розробника

```bash
npm install                                           # один раз: puppeteer-core, typescript, react, vue, esbuild
node tools/build-ts-vendor.js                         # зібрати vendor/typescript (після оновлення typescript)
node tools/build-react-vendor.js                      # зібрати vendor/react (після оновлення react)
node tools/build-vue-vendor.js                        # зібрати vendor/vue (після оновлення vue)
npm run check                                         # усе: валідатор, порядок понять, квізи, покриття, підручник
node tools/validate.js js-async vue-basics            # один або кілька модулів у справжньому Chrome / Edge
npm run coverage -- --all                             # покриття канонічної програми по кожній темі
npm run book                                          # кожен крок має підрозділ у підручнику
node tools/append-items.js dom patch.js               # дописати кроки і завдання в модуль (з перевіркою синтаксису)
node tools/screenshot.js shots "#/" "#/track/js-core"  # скриншоти (--mobile, --light)
node tools/topic-map.js js-async --todo               # карта модуля
```
